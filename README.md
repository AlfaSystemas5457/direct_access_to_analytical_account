# 📦 Acceso directo a una cuenta analitica

Este módulo permite un acceso simple y rapido a las cuentas analíticas.

## 🚀 Compatible con versiones de Odoo  
Este módulo es compatible con *Odoo Community 18.0*.

🔗 [Repositorio en GitHub](https://github.com/AlfaSystemas5457/direct_access_to_analytical_account)

---

## 📊 Acceso facil a las cuentas analíticas

Se agrega un boton para acceder en los botones del modulo *project*

## 📥 Instalación

Para instalar este módulo, sigue estos pasos:

- Descargar el repositorio:

```bash
git clone https://github.com/AlfaSystemas5457/direct_access_to_analytical_account
```
- Copiar la carpeta del módulo en la ruta de addons de Odoo.
- Actualizar la lista de módulos en Odoo.
- Instalar el módulo desde la interfaz de Odoo.
